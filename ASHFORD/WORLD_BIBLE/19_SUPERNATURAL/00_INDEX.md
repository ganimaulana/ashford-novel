# 19_SUPERNATURAL — Index

**PURPOSE:** Dedicated layer for how the supernatural works in Ashford — rules, principles, entities, artifacts, rituals, soul, death, dreams, corruption, and the explicitly unknown.

**DISTINCTION (important):**
- `07_ANOMALIES/` = **What exists / what happens** (phenomena, entities, artifacts, location anomalies)
- `09_MYSTERY/` = **What is unknown** (questions, clues, secrets, revelations)
- `19_SUPERNATURAL/` = **How it works** (rules, mechanisms, limitations, metaphysics)
- `14_CANON/` = **What is true** (final, canonized facts)
