# ANOMALIES Directory

## Overview

This directory contains the **ARC (Anomalous Record Catalogue)** system - the classification framework for supernatural/paranormal phenomena dalam dunia Alderwick.

**PENTING:** ARC adalah sistem **INTERNAL UNDERGROUND**, bukan organisasi, dan **TIDAK DIKETAHUI PUBLIC**.

---

## Core Files

### 10_ARC_SYSTEM.md
Complete documentation sistem ARC - format penamaan, categories, risk levels, principles.
**Start here untuk understand the system.**

### 16_UNIVERSAL_RULES.md
The Ten Rules yang diikuti underground network ketika dealing dengan anomalies.

### 12_CLASSIFICATION_GUIDE.md
Quick reference untuk category definitions dan risk levels.

Master catalogue tracking all ARC cases (currently empty - awaiting canon cases).

## Key Principles

1. **ARC ≠ SCP** - Different scale, tone, goals, methods
2. **Underground ≠ Organization** - Informal network, bukan military
3. **Rules ≠ Laws** - Guidelines learned through experience
4. **Leon ≠ Expert** - Develops understanding over time
5. **Arthur = Historian** - Not paranormal expert
6. **Not Everything Is Supernatural** - Some cases MISIDENTIFIED
7. **Limitations Matter** - Every anomaly has constraints
