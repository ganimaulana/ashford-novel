## Usage Notes

### Adding New Case

Ketika case baru dikonfirmasi:

1. Create file dalam `Cases/` folder
2. Use ARC file template dari `10_ARC_SYSTEM.md`
3. Assign ARC number (next available)
4. Update master list di sini
5. Mark sebagai appropriate status

### Draft Cases

Draft cases di `Draft/` folder:
- 08_ARC_008 — The Returning Coin
- 13_ARC_013 — The Thirteenth Key  
- ARC-021 — The Bellweather Clock

These are **EXAMPLES ONLY** - not canon sampai used dalam story.

### Numbering System

Numbers assigned sequentially ketika case officially catalogued.

**Reserved Ranges:**
- 001-099: General cases
- 100-199: Location-specific
- 200-299: Person-related
- 300-399: Event-based
- (etc. - this is flexible)

**PENTING:** Number tidak menunjukkan danger level atau priority.

## Information Control

### Public Knowledge: NONE

Masyarakat Alderwick **TIDAK TAHU**:
- ARC system exists
- Cases are being catalogued
- Underground network tracking anomalies

### Underground Network Knowledge

Underground members mungkin tahu:
- Beberapa cases exist
- General patterns
- Specific cases mereka involved dalam

**TETAPI:**
- Tidak semua members tahu semua cases
- Information sharing selective
- No central database accessible to all

### Leon's Access

Leon mengetahui cases yang:
- Dia personally investigated
- Shared dengan him by network
- He discovered independently
