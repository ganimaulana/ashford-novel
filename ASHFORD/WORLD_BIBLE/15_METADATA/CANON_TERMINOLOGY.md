# SUPERNATURAL SYSTEM

The Ashford supernatural system consists of:

```
SUPERNATURAL SYSTEM
│
├── XIII SIGNS
│
└── NINE RANKS
```

The **XIII Signs** represent distinct supernatural identities.
The **Nine Ranks** represent progression within each Sign.

The official designation format is:

```
[RANK TITLE] + [SIGN]
```

Example (Knight Sign):

```
Marked Knight
Bound Knight
Resonant Knight
Attuned Knight
Ascendant Knight
Crowned Knight
Exalted Knight
Sovereign Knight
Transcendent Knight
```

## SIGN VS RANK — FUNDAMENTAL DISTINCTION

- **SIGN** = the supernatural identity/path.
- **RANK** = the person's level of progression within that Sign.

Therefore:
- Knight ≠ Rank
- Marked ≠ Sign
- **Marked Knight** = Rank 9 (lowest) + Knight Sign
- **Transcendent Knight** = Rank 1 (highest) + Knight Sign

The Sign determines WHAT kind of supernatural identity the person possesses. The Rank determines HOW FAR that identity has developed.
