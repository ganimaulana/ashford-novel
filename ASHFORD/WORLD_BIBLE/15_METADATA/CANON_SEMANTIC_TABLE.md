## ARTIFACT TAXONOMY

```
ARTIFACT
├── GEAR
├── TOKEN
└── OTHER SUPERNATURAL ARTIFACTS
```

Gear and Token are both physical supernatural objects, but they are NOT the same thing. Other artifacts may exist without being Gear or Token.

## ERC SUBJECT TAXONOMY

ERC subject types: OBJECT · PHENOMENON · LOCATION · ENTITY · EVENT · DOCUMENT · RITUAL · MECHANISM · UNKNOWN.

These are SUBJECT TYPES recorded by ERC. They do not replace Artifact taxonomy.

```
ERC Record
→ Subject Type: OBJECT
→ Subject: ancient Gear

The record is ERC. The physical object is an Artifact. The specialized object type is Gear.
```

## THE RECORD vs SUBJECT RULE (ENFORCED)

ERC names a RECORD / CLASSIFICATION, never the subject itself.

- CORRECT: "An ERC record documents an unidentified ancient mechanism."
- INCORRECT: "The mechanism is an ERC."
- CORRECT: "The object is an Artifact." / "The Artifact is identified as a Gear." / "Leon discovers a Gear."
- INCORRECT: "Leon discovers an ERC" — unless he discovers a record/document classified under ERC.

Being supernatural does NOT automatically make something an ERC subject. A Gear is NOT automatically an ERC. A Token is NOT automatically an ERC. The Sanctuary is not automatically an ERC — if it appears in an archival record, the RECORD may be associated with ERC.

## ERC NUMBERING

ERC-001, ERC-002… are RECORD DESIGNATIONS. They do NOT represent power, danger, rarity, Gear count, Token count, Rank, or necessarily chronology. ERC-100 is not automatically stronger than ERC-010. No "ERC Level/Tier/Power/Danger Rank" concepts exist.

## ARC vs ERC

- ARC = narrative structure (Arc 1, Arc 2, Arc 3 remain valid; do not change narrative references).
- ERC = Esoteric Record Classification.
- Legacy object designations "ARC-001…ARC-021" migrated to ERC-001…ERC-021 as record designations. Migration of a designation does NOT automatically make its subject an Artifact — each subject's semantic category follows existing canon (e.g., The Returning Coin's category is determined by its own case material, not by its former ARC number).

## FORBIDDEN CONFLATIONS

- "Gear is an ERC." ✗
- "Gear carries an ERC designation." ✗ (the RECORD about a Gear may)
- "Token is an ERC." ✗
- "ERC determines artifact power." ✗
- "Gear number determines strength." ✗
- "ERC is the supernatural hierarchy." ✗
- "Door is an ERC." ✗
- "Sanctuary is a Gear." ✗
- "Sign is an Artifact." ✗ (unless a specific canon context explicitly requires it)

## KNOWLEDGE BOUNDARIES (PRESERVED)

Different characters/organizations understand different layers: "an old artifact" → "it has unusual properties" → "it is a Gear" → "a mechanism associated with the Door". Nobody necessarily understands the complete purpose. A rival organization may possess a Gear without knowing its Door connection. Information asymmetry is intentional.
