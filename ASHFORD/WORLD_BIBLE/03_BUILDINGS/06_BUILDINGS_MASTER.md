## Notes untuk Penulis

### Saat Memperkenalkan Bangunan Baru:

1. **Periksa** apakah bangunan sudah disebutkan
2. **Catat** di file ini
3. **Buat file detail** jika bangunan signifikan
4. **Tentukan** periode arsitektur
5. **Pastikan** lokasi konsisten dengan tata kota

### Saat Mendeskripsikan Bangunan:

1. **Konsistensi** - Deskripsi harus sama setiap kali disebutkan
2. **Detail spesifik** - Hindari deskripsi generik
3. **Kontras** - Bangunan tua vs baru, terawat vs terbengkalai
4. **Fungsi** - Bagaimana bangunan digunakan sekarang?
