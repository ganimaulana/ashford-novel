# Alderwick WORLD BIBLE

## Purpose

Central repository for Alderwick canon, world-building, mystery, timeline, metadata, and supporting references.

## Structure

- **14_CANON/** – Authoritative narrative/world rules and continuity constraints.
- **15_METADATA/** – Project state, canon logs, chapter status, and current world state.
- **16_GOVERNMENT/** — Political framework, government structure, factions, and Alderwick magistracy.
  - `GOVERNMENT_BIBLE.md` — Full political framework
  - `HISTORICAL_CORRESPONDENCE.md` — Mapping between Alderwick canon and historical analogues
  - `POLITICAL_FACTIONS.md` — Detailed faction descriptions
  - `GOVERNMENT_CHARACTERS.md` — Political character profiles
- **17_ORGANIZATIONS/** — Dedicated layer for organizations, factions, societies, clubs, and institutions.
  - `00_INDEX.md` — Index and cross-reference
  - `09_RELIGIOUS.md`, `05_GOVERNMENT.md`, `01_ACADEMIC.md`, `08_OCCULT.md`, `03_CRIMINAL.md`, `10_SOCIAL.md`, `02_ARISTOCRATIC.md`, `07_MILITARY.md`, `11_UNDERGROUND.md`, `06_HISTORICAL.md`, `04_FACTIONS.md`
  - Existing files (e.g., `08_UNDERGROUND/08_ORDER_OF_SEVERENCE.md`) remain in their original locations; this layer cross-references them.
- **18_RELIGION_THEOLOGY/** — Dedicated layer for religious doctrine, theology, rituals, symbols, heresies, and occult theology.
  - `00_INDEX.md` — Index
  - `02_DOCTRINE.md` through `04_OCCULT_THEOLOGY.md`
- **19_SUPERNATURAL/** — Dedicated layer for how the supernatural works: rules, principles, entities, artifacts, soul, death, dreams, corruption, and the explicitly unknown.
  - `00_INDEX.md` — Index (distinguishes this layer from `07_ANOMALIES` and `09_MYSTERY`)
  - `08_PRINCIPLES.md` through `12_UNKNOWN.md`
  - Master six-system framework: `WORLD_BUILDING/Alderwick_Power_System.md` (CANON v1.2)
- **09_MYSTERY/** – Mystery architecture, clues, confirmed reveals, character knowledge, and unresolved questions.
- **10_TIMELINE/** – Chronological events and historical continuity.
- **01_GEOGRAPHY/** – Physical, social, historical, geographical, architectural, business, district, street, anomaly, and other setting information.
- **13_REFERENCE/** – Supporting frameworks, external references, non-canon ideas, and reference material.

## Reading Priority

When resolving conflicting information, prioritize:

1. CANON
2. METADATA
3. MYSTERY
4. TIMELINE
5. WORLD
6. REFERENCE

## AI Rules

- Do not invent canon.
- Do not convert proposals into canon.
- Respect character knowledge boundaries.
- Respect mystery reveal boundaries.
- Respect timeline constraints.
- Do not treat 01_IDEAS_NOT_CANON as canon.
- When sources conflict, report the conflict rather than silently rewriting information.
- File location alone does not determine canon status.
