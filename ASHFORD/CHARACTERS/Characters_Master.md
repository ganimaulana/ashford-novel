## Notes untuk Penulis

### Saat Memperkenalkan Karakter Baru:

1. **Periksa daftar ini** untuk memastikan tidak ada duplikasi nama/peran
2. **Buat file detail** untuk karakter yang signifikan
3. **Update** file `Character_Knowledge.md` jika karakter tahu tentang mystery
4. **Catat** hubungan dengan karakter lain

### Saat Menulis Karakter yang Sudah Ada:

1. **Baca file detail** karakter tersebut
2. **Periksa pengetahuan** karakter di `Character_Knowledge.md`
3. **Pastikan konsisten** dengan kemunculan sebelumnya
4. **Update file** jika ada informasi baru
