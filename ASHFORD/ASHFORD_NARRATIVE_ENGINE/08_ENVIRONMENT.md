# System 08 — Environment

**Status:** CORE SYSTEM | **Created:** 2026-08-29 | **Updated:** 2026-08-29 for 1816 canon
**LOTM Transfer:** Rule 1 (grounded sensory detail)
**Evidence Confidence:** 9/10 (excellent district/building documentation)
**Era:** 1816 Regency England

---

## A. PURPOSE

Treat locations as narrative systems, not backdrops. Each important place communicates history, character, tension, social class, memory, and anomaly.

## B. ENVIRONMENTAL IDENTITY

For every important location, track:

| Dimension | Question |
|-----------|----------|
| Physical Identity | What does it look like? What materials? What era? |
| Sensory Signature | What does it smell like? Sound like? Feel like? |
| Social Function | Who uses it? For what purpose? |
| History | What has happened here? What is built into this place? |
| Emotional Association | What does this place mean to each character? |
| Recurring Details | What specific element repeats across chapters? |
| Changes Over Time | How does the place evolve or how does perception of it change? |
| Mystery Relationship | How does this place connect to the central mystery? |

## C. OPERATIONAL RULES

1. **No location is visited more than once without a new detail or changed perception.** Repetition requires evolution.
2. **Every location description must include at least one sensory element beyond visual.** Smell, sound, texture, temperature.
3. **Location details should serve the scene.** If a described feature doesn't matter to the scene, remove it.
4. **Buildings carry history.** Architecture is evidence. Period style reveals social class and era.
5. **Locations change across the story.** By the end, Leon's house should feel different than it did at the start.

## D. WHEN TO USE

- Every scene set in a named or recurring location
- Every new location introduction
- Every scene where location mood contributes to tension or atmosphere
- Every time the reader returns to a familiar location

## E. WHEN NOT TO USE

- Scenes where the specific location doesn't matter
- Purely interior scenes set in generic rooms
- Transitional moments where location is incidental

## F. FAILURE MODES

| Failure | Sign | Fix |
|---------|------|-----|
| Generic description | Location could be anywhere | Add specific Ashford details |
| Repetition without change | Same details appear every visit | Add new detail or changed perception |
| Backdrop only | Location doesn't communicate anything | Add meaning (history, class, memory) |
| Over-description | Paragraph of pure description with no scene purpose | Cut or integrate with action |

## G. QA QUESTIONS

- [ ] Does this location have a unique sensory signature?
- [ ] Does the location communicate something beyond its physical appearance?
- [ ] If the reader returns to this location, is there something new?
- [ ] Does the building's era/architecture tell a story?
- [ ] Is the location connected to the mystery?
