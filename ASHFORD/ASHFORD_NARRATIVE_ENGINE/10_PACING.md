# System 10 — Pacing

**Status:** CORE SYSTEM | **Created:** 2026-08-29
**LOTM Transfer:** Rules 2, 10 (gradual progression, structured progression)
**Evidence Confidence:** 7/10 (good implicit support in Ch 1-8)

---

## A. PURPOSE

Create a pacing model for long-form mystery that tracks intensity, information density, emotional weight, and energy at every level — sentence, scene, chapter, arc, novel.

## B. PACING DIMENSIONS

| Dimension | What It Tracks |
|-----------|---------------|
| Scene Intensity | How tense or consequential is this scene? |
| Information Density | How many new facts/clues per scene? |
| Emotional Intensity | How emotionally charged is this scene? |
| Action | Physical movement or events |
| Reflection | Internal thought, reading, analysis |
| Discovery | New information, new understanding |
| Uncertainty | How much does the scene increase or decrease uncertainty? |
| Recovery | Emotional or mental decompression |
| Escalation | Is the stakes increasing? |

## C. PACING LEVELS

### Sentence Level
- Short sentences = urgency, tension, clarity
- Long sentences = reflection, description, ease
- Rhythm variation prevents monotony

### Scene Level
- High-tension scene: action + discovery + low recovery
- Medium-tension scene: information + reflection + some discovery
- Low-tension scene: atmosphere + relationship + recovery

### Chapter Level
- A chapter does NOT need to end in a cliffhanger
- Chapter endings should match the chapter's emotional movement

### Arc Level
- Pressure and release cycles within each arc
- Escalation is gradual, not linear
- Mid-arcs should contain both discovery and reflection

### Novel Level
- Overall arc: mystery deepens gradually
- Tension builds but with breathing room
- Peak tension at arc/novel climax
- Resolution provides both closure and deeper questions

## D. PACING CYCLE

```
CURIOSITY (information gap created)
  -> COMFORT (character understands situation)
  -> DISCOMFORT (something doesn't fit)
  -> ESCALATION (stakes increase)
  -> PRESSURE (character must act)
  -> DISCOVERY (new information changes understanding)
  -> RECOVERY (decompression, reflection)
  -> [Repeat at higher level]
```

## E. OPERATIONAL RULES

1. **Not every chapter needs to be tense.** The reader needs recovery periods.
2. **Information density should vary.** Some chapters are clue-heavy; others are reflection-heavy.
3. **Escalation must be gradual.** Jump from calm to crisis without buildup feels unearned.
4. **Each chapter's ending should match its emotional movement.** A reflective chapter can end quietly. A tense chapter can end with revelation or decision.
5. **Track pacing across consecutive chapters.** If three chapters are all high-tension, insert recovery before the next escalation.

## F. WHEN TO USE

- Every chapter planning phase
- Every scene type decision
- Arc-level planning
- Novel-level structure review

## G. WHEN NOT TO USE

- Don't force tension into recovery scenes
- Don't make every chapter structurally identical
- Don't use pacing to mask weak plot — pacing is seasoning, not main course

## H. FAILURE MODES

| Failure | Sign | Fix |
|---------|------|-----|
| Uniform tension | Every chapter is equally intense | Vary pacing deliberately |
| No recovery | Reader fatigue from constant tension | Add reflection/relationship scenes |
| Pacing without plot | Scenes feel tense but nothing happens | Add plot advancement to tension |
| Cliffhanger dependency | Every chapter ends with "to be continued" | Use varied chapter endings |

## I. ASHFORD-SPECIFIC IMPLEMENTATION

- Leon's investigative method creates natural pacing: discovery (high) -> analysis (low) -> discovery (high)
- Archive/library scenes = information density peaks
- Walk-through scenes = reflection/atmosphere recovery
- Social scenes (cafe, meetings) = relationship/pacing release
- Supernatural moments = pressure peaks — must be preceded by calm buildup
- Chapter endings in published work show variety: revelation, quiet transition, emotional shift
