# System 11 — Scene Construction

**Status:** CORE SYSTEM | **Created:** 2026-08-29
**LOTM Transfer:** Rules 1, 3, 4, 16 (grounded detail, information exchange, physical revelation, action-analysis)
**Evidence Confidence:** 8/10 (strong canon support)

---

## A. PURPOSE

Create a flexible scene model where every scene has clear purpose, tension, information state, and consequence — without requiring every scene to perform every function.

## B. SCENE ELEMENTS

Every scene should have (at minimum):

| Element | Purpose |
|---------|---------|
| Immediate Purpose | What does this scene accomplish? |
| Character Objective | What does the protagonist want in this scene? |
| Obstacle or Tension | What prevents easy success? |
| Information State | What does everyone know at scene start vs end? |
| Emotional State | What is the emotional trajectory? |
| Sensory Grounding | What physical details anchor the scene? |
| Turning Point | What changes during this scene? |
| Consequence | What is different after this scene? |

## C. SCENE FUNCTIONS (Pick Primary + Optional)

A scene has ONE PRIMARY function and may have optional secondary functions:

| Function | Description |
|----------|------------|
| **Character** | Reveals or develops a character |
| **Worldbuilding** | Introduces world information |
| **Mystery** | Advances a mystery thread |
| **Relationship** | Develops character dynamics |
| **Atmosphere** | Establishes or shifts mood |
| **Information** | Delivers new facts/clues |
| **Transition** | Moves from one state/location to another |
| **Escalation** | Raises stakes |
| **Consequence** | Shows aftermath of previous events |

A scene may serve multiple functions but should have ONE clear primary purpose.

## D. MULTI-PURPOSE SCENES

Encourage multi-purpose scenes. A scene that simultaneously develops character AND advances mystery AND establishes atmosphere is ideal — but only when the functions feel organic, not forced.

## E. OPERATIONAL RULES

1. **Every scene must have a purpose.** If you can't name what the scene accomplishes, reconsider it.
2. **Every scene must contain tension.** Tension doesn't mean conflict — it can be uncertainty, curiosity, discomfort, or anticipation.
3. **Every scene must change something.** If nothing different at the end, the scene shouldn't exist.
4. **Information states must shift.** Characters know something at scene end they didn't know at start — or they've gained/lost understanding.
5. **Sensory grounding must be established early.** The first few sentences should anchor the reader physically.

## F. WHEN TO USE

- Every scene in every chapter
- Scene planning before writing
- Scene revision during drafting

## G. WHEN NOT TO USE

- Don't force every element into every scene. A pure atmosphere scene may only have atmosphere + transition.
- Don't require cliffhanger endings in every scene.

## H. FAILURE MODES

| Failure | Sign | Fix |
|---------|------|-----|
| Purposeless scene | Can't name what scene accomplishes | Cut or add purpose |
| No tension | Scene feels flat or boring | Add uncertainty, curiosity, or conflict |
| Static scene | Nothing changes from start to end | Add a turning point |
| Overloaded scene | Trying to do too many things at once | Split into separate scenes |

## I. ASHFORD-SPECIFIC IMPLEMENTATION

- Common Ashford scene types:
  - **Archive/Investigation scene:** Mystery (primary) + Information (secondary) + Worldbuilding (secondary)
  - **Social conversation scene:** Relationship (primary) + Information (secondary)
  - **Walk/observation scene:** Atmosphere (primary) + Character (secondary)
  - **Discovery scene:** Mystery (primary) + Information (primary) + Escalation (secondary)
  - **Interior reflection scene:** Character (primary) + Atmosphere (secondary)
- Leon's notebook is often the turning point mechanism — he writes, then sees something new

## J. CROSS-SYSTEM DEPENDENCIES

- **Information Control** — Scene information state is tracked here
- **Mystery Engine** — Mystery scenes are the primary plot drivers
- **Character Depth** — Character scenes reveal dimension
- **Pacing** — Scene intensity contributes to chapter-level pacing
- **Atmosphere** — Sensory grounding is atmosphere in micro
