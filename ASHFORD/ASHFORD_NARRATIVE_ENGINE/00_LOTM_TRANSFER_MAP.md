# LOTM Research Transfer Map

**Status:** WORKING DOCUMENT | **Date:** 2026-08-29
**Purpose:** Map LOTM-derived narrative principles to Ashford-adapted rules

---

## METHODOLOGY

For each LOTM finding:
1. Identified the abstract mechanism
2. Removed source-specific elements
3. Tested fit against CURRENT Ashford canon
4. Classified: CORE / ADAPTABLE / OPTIONAL / PROVISIONAL / REJECTED
5. Recorded evidence/confidence status

---
