## A. PURPOSE

Build atmosphere through concrete sensory elements — never as ornamental description with no story purpose. Every atmospheric detail must serve the narrative.

## B. ATMOSPHERE ELEMENTS

| Element | Narrative Function |
|---------|-------------------|
| Light | Mood, revelation, concealment |
| Sound | Tension, ordinary life, silence as pressure |
| Smell | Memory, physical reality, era grounding |
| Temperature | Discomfort, physical state, season |
| Texture | Tactile reality, physical interaction |
| Spatial feeling | Claustrophobia, openness, disorientation |
| Social behavior | Community life, isolation, normality |
| Silence | Absence, tension, anticipation |
| Weather | Mood, mood change, period grounding |
| Character perception | How atmosphere filters through Leon's mind |

## C. OPERATIONAL RULES

1. **Every atmospheric detail must serve the narrative.** If it doesn't establish mood, character, foreshadowing, or era, remove it.
2. **Atmosphere serves mood, but mood serves the scene's purpose.** Don't build atmosphere for its own sake.
3. **Avoid ornamental adjectives.** "Mysterious," "dark," "eerie" are forbidden generic atmospheric words. Show through concrete detail.
4. **Atmosphere changes with Leon's emotional state.** A place feels different when Leon is curious vs afraid.
5. **Weather and environment are era-appropriate.** Rain, fog, cold, candlelight, or period-appropriate elements.

## D. WHEN TO USE

- Every scene opening (establish mood immediately)
- Every transition between locations
- Every supernatural threshold moment
- Every scene where Leon's emotional state needs anchoring

## E. WHEN NOT TO USE

- Information-heavy scenes where atmosphere distracts from clarity
- Fast-paced discovery scenes
- Pure dialogue exchanges where mood is already established

## F. FAILURE MODES

| Failure | Sign | Fix |
|---------|------|-----|
| Ornamental description | Beautiful description that advances nothing | Cut or connect to scene purpose |
| Generic adjectives | "Dark," "eerie," "mysterious" | Replace with concrete sensory detail |
| Atmospheric overload | Every paragraph has atmosphere | Reduce to key moments |
| Mood mismatch | Atmosphere doesn't match scene purpose | Revise to serve the scene |
