# Foreshadowing Ledger Template

**Purpose:** Track foreshadowing setups and their planned/payoff states across the novel.
**Used By:** System 03 (Foreshadowing & Payoff), System 13 (Long-Range Arc)
**Status:** TEMPLATE — ready for Arc 001 entry

---

## HOW TO USE

Each foreshadowing entry tracks:
- **Setup Chapter:** Where the foreshadowing element appears
- **Foreshadowing Element:** What is planted (object, symbol, line, behavior)
- **Payoff Chapter:** Where the element resolves (or "TBD" if not yet planned)
- **Payoff Type:** Reveal, confirmation, callback, subversion
- **Importance:** Core (drives main plot), Important (supports main plot), Minor (atmospheric)
- **Status:** Planted, Observed by reader, Confirmed, Disproven, Resolved, Dropped

## LEGEND

### Payoff Types
- **Reveal:** The element is explained or its meaning is disclosed
- **Confirmation:** Something previously suspected is verified
- **Callback:** A minor element referenced again for emotional effect
- **Subversion:** The element's meaning is inverted or contradicted

### Importance Levels
- **Core:** Drives the central mystery. Must pay off.
- **Important:** Supports central mystery. Should pay off.
- **Minor:** Atmospheric or character flavor. Can be dropped if needed.

### Statuses
- **Planted:** Element introduced in text
- **Observed by reader:** Reader has likely noticed and formed hypothesis
- **Confirmed:** In-story fact has been verified
- **Disproven:** In-story fact has been invalidated
- **Resolved:** Payoff has occurred
- **Dropped:** Element intentionally left unexplained (rare — use only if narratively justified)
