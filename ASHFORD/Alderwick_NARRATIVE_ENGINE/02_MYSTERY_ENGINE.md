# System 02 — Mystery Engine

**LOTM Transfer:** Rules 3, 4, 5 (information exchange, physical revelation, sensory grounding)
**Evidence Confidence:** 8/10 (strong canon support via Pembroke & Clarke letter framework)
**Era:** 1816 Regency England

---

## A. PURPOSE

Structure mystery progression through a repeatable cycle: Question -> Observation -> Clue -> Interpretation -> Hypothesis -> Contradiction -> New Evidence -> Revised Hypothesis -> Partial Answer -> Deeper Question -> Revelation.

## B. CORE PRINCIPLES

1. **Every mystery element has a causal chain.** Nothing happens by coincidence in Alderwick.
2. **Clues must be fair.** The reader sees the clue before Leon fully interprets it.
3. **Misinterpretation is expected.** Leon's first reading of evidence should often be wrong or incomplete.
4. **Answers must open deeper questions.** Resolution should not end the mystery — it should deepen it.

## C. MECHANISMS

### Mystery Cycle

```
QUESTION (what needs answering)
  -> OBSERVATION (something noticed that generates the question)
  -> CLUE (physical evidence, document, conversation fragment)
  -> INTERPRETATION (Leon's first reading of the clue)
  -> HYPOTHESIS (Leon's working theory)
  -> CONTRADICTION (new evidence that conflicts with the hypothesis)
  -> NEW EVIDENCE (something discovered that forces revision)
  -> REVISED HYPOTHESIS (Leon updates understanding)
  -> PARTIAL ANSWER (enough is known to move forward, but not everything)
  -> DEEPER QUESTION (the partial answer reveals a more fundamental question)
  -> REVELATION (the moment of understanding — or a more profound mystery)
```

### Mystery Types

| Type | Mechanism | Example |
|------|-----------|---------|
| Document mystery | Information found in records | Pembroke & Clarke letter |
| Environmental mystery | Physical space holds clues | Bellweather House absence from records |
| Behavioral mystery | Character actions reveal hidden knowledge | Helen's watchfulness |

## D. OPERATIONAL RULES

1. **Every clue must be discoverable.** If the reader can't find it, it's not a clue — it's a cheat.
2. **Information travels at 1816 speed and methods.** Leon must PHYSICALLY visit locations, read documents, and talk to people. No instant digital retrieval.
3. **Clues are physical and tangible.** Documents, objects, observations, conversations — never a computer search result.
4. **Investigation requires physical effort.** Leon walks to the library, visits the church, reads parish records, talks to the vicar.
5. **Misinformation and confusion are natural.** In a world without instant verification, characters work from incomplete, unverified information.
2. **Every hypothesis must face contradiction.** Leon's theories should be challenged before confirmed.
3. **Partial answers must precede full reveals.** Jump from question to answer without intermediate steps feels unearned.
4. **The deeper question must be THEMATICALLY connected to the partial answer.** It should feel like the natural next layer, not a random twist.
5. **No random coincidences.** If two pieces of evidence connect, show the causal link.

## E. WHEN TO USE

- Every chapter must advance at least one mystery thread
- Multiple mysteries can run in parallel but must intersect
- The central mystery (Aurelius/Ashcroft connection) drives the overall structure
- Sub-mysteries (local anomalies, character secrets) provide chapter-level engagement

## F. WHEN NOT TO USE

- Simple transitional scenes (not every scene needs a mystery beat)
- Pacing-release scenes (the reader needs breathing room)
- Pure relationship development scenes

## G. FAILURE MODES

| Failure | Sign | Fix |
|---------|------|-----|
| Coincidence dependency | Two clues connect by random chance | Add a causal chain between them |
| Fairness violation | Reader could not have suspected the answer | Plant the clue earlier in a different context |
| Answer inflation | The reveal is bigger than the clues support | Scale the reveal to the evidence |
| Mystery bloat | Too many parallel mysteries with no intersection | Consolidate or eliminate threads |
