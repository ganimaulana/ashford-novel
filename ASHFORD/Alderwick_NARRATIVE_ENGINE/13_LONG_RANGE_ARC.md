# System 13 — Long-Range Arc

**Status:** CORE SYSTEM | **Created:** 2026-08-29
**LOTM Transfer:** Rules 2, 10 (gradual progression, structured progression)
**Evidence Confidence:** 7/10 (good arc structure, needs better tracking)

---

## A. PURPOSE

Build long-range story engineering that connects setups to payoffs across the entire novel. Prevent episodic mystery, escalation without foundation, sudden character changes, and disconnected subplots.

## B. LONG-RANGE ELEMENTS

| Element | Question |
|---------|----------|
| Arc Objective | What does this arc accomplish in the overall story? |
| Protagonist Development | How does Leon change by the end of this arc? |
| Mystery Progression | What new layer of mystery is introduced? |
| World Revelation | What new understanding of Alderwick emerges? |
| Relationship Progression | How do key relationships evolve? |
| Escalation | How do stakes increase compared to earlier arcs? |
| Setup | What new elements are introduced for future arcs? |
| Midpoint Changes | What fundamentally shifts at the arc's center? |
| Consequences | What changes as a result of this arc? |
| Payoff | What earlier setups resolve? |

## C. ARC DEPENDENCIES

A later arc should benefit from earlier setup. Track:

| Dependency Type | Description |
|----------------|------------|
| Knowledge dependency | Arc B requires knowledge from Arc A |
| Relationship dependency | Arc B requires relationship state from Arc A |
| Object dependency | Arc B requires an object introduced in Arc A |
| Location dependency | Arc B requires knowledge of a location from Arc A |
| Character dependency | Arc B requires character development from Arc A |

## D. OPERATIONAL RULES

1. **Every arc must connect to the central mystery.** No episodic standalone plots.
2. **Setups in early arcs must have planned payoffs.** Unresolved setups become plot holes.
3. **Escalation must be earned.** Each arc's stakes must build on earlier arcs.
4. **No sudden character changes.** Character shifts must be foreshadowed by gradual development.
5. **Subplots must connect to the main narrative.** Branching is fine; isolation is not.

## E. ARC STRUCTURE

```
EARLY ARC (Setup)
  - Introduce core mystery elements
  - Establish character baseline
  - Build world foundation
  - Plant foreshadowing
  - Low stakes, high curiosity

MIDDLE ARC (Deepening)
  - Mystery deepens through investigation
  - Character relationships develop
  - World reveals hidden layers
  - Stakes increase
  - Midpoint: fundamental understanding shifts

LATE ARC (Convergence)
  - Earlier setups pay off
  - Character reaches breaking point or transformation
  - Mysteries intersect
  - High stakes, high tension
  - Resolution or deeper mystery
```

## F. WHEN TO USE

- Planning each new arc
- Reviewing arc structure during revision
- Checking that new material connects to established arcs
- Novel-level structural planning

## G. WHEN NOT TO USE

- Don't force every chapter into the arc framework
- Don't plan every detail of future arcs — leave room for discovery
- Don't create rigid chapter-by-chapter outlines

## H. FAILURE MODES

| Failure | Sign | Fix |
|---------|------|-----|
| Episodic mystery | Arc feels disconnected from previous arcs | Add connection to established plot threads |
| Escalation without foundation | Stakes jump without setup | Add setup in earlier arc |
| Sudden character change | Character transforms without gradual development | Map progression across arcs |
| Disconnected subplot | Subplot never intersects with main story | Connect subplot to central mystery |

- **Character Progression** — Arcs drive character development
