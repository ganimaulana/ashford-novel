# Social Event as Plot Engine — Ashford, 1816

**Status:** PROPOSED — to be confirmed as canon after review.

## Overview

This document maps the potential plot functions of every social institution and event in Ashford. Social events are not just worldbuilding; they are engines for character development, relationship formation, information exchange, and mystery.

---

## Event → Plot Function Matrix

| Event Type | Potential Plot Functions |
|------------|--------------------------|
| **Fair** | Introduction of outsider; disappearance; theft; fraud; political rally; romantic meeting; class conflict; rumor spread. |
| **Festival** | Public scandal; revelation; political protest; disappearance; supernatural incident; court society; cross-class mixing. |
| **Tavern** | Secret meeting; confession; fight; overheard conversation; criminal transaction; recruitment; gambling debt. |
| **Ball/Dance** | Courtship; rivalry; scandal; proposal; jealousy; disguise; overheard secrets; social display; class commentary. |
| **Theatre/Performance** | Mirroring of real events; actor with a secret; hidden message in play; public scandal; private conversation in box. |
| **Church Service** | Confession; secret revelation; community gossip; moral judgment; hidden document; religious conflict. |
| **Lecture/Debate** | Political conflict; intellectual rivalry; secret society; dangerous ideas; recruitment. |
| **Reading Evening** | Discussion of forbidden ideas; revelation of character; hidden clue in book; private conversation. |
| **Public Ceremony** | Political theater; display of power; crowd scenes; announcement of news; civil unrest. |
| **Funeral** | Family conflict; will dispute; hidden secret; mourning display; inheritance crisis. |
| **Wedding** | Love triangle; family conflict; class commentary; secret affair; financial scandal; romantic reunion. |
| **Hiring Fair** | Servant with a secret; labor dispute; false identity; disappearance; employment of a spy. |
| **Market** | Gossip; economic conflict; theft; discovery of a stranger; information exchange; criminal activity. |
| **Nightlife** | Illicit meeting; crime; murder; confession; discovery; conspiracy. |

---

## Event Integration

Every event should be used to advance at least one of the following:
- **Character introduction:** Introduce a new character.
- **Relationship development:** Deepen or complicate relationships.
- **Information exchange:** Reveal a clue or rumor.
- **Conflict:** Political, class, or personal conflict.
- **Romance:** Courtship, jealousy, or love.
- **Crime:** Theft, fraud, violence.
- **Disappearance:** A person vanishes.
- **False Lead:** Provide a misleading clue.
- **Witness Gathering:** Many people see something.
- **Hidden Meeting:** A secret rendezvous.
- **Supernatural Incident:** A strange occurrence.
- **Public Scandal:** A reputation is destroyed.
- **Revelation:** A hidden truth is revealed.

---

## Important Note

Events must remain organic. Do not turn every festival or tavern scene into a murder mystery. Use events to create atmosphere, develop characters, and advance the plot naturally.
